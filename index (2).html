What's new in v2 — Canva-inspired

Layout language borrowed from Canva's editor (icon rail, sliding panels, contextual toolbar, bottom strip, Share-style export) — restyled in Resizora's dark indigo-cyan identity.

1

Left icon rail + sliding panel

Canva's signature: a narrow icon rail (Upload · Presets · Resize · Crop · Adjust · Filters · Mark) opens a contextual panel beside it — no more tab-hunting on the right.

2

Contextual top toolbar

The bar under the header changes with the active tool — pick Crop and it offers aspect chips + Apply/Cancel right where your eyes are, like Canva's formatting bar.

3

Bottom filmstrip batch

Batch images moved to a horizontal strip (Canva's pages strip) — click to jump between images, each showing live size savings.

4

Download button → export panel

One prominent Download button top-right opens the export settings as a slide-over — Canva's Share pattern. Format, quality, naming and ZIP in one place.

5

Preset gallery with visual cards

Social presets are now visual aspect-ratio cards you can browse and search — applying one is a single click, like picking a Canva template.

6

Floating zoom controls

Zoom − / % / + sits bottom-right of the canvas, Canva-style — always at hand, never in the way.

7

Friendly empty state

Before images load, a warm dropzone card (drag, browse, or one-click demo images) replaces the blank canvas — Canva's welcoming first screen.

8

Draggable crop box

Crop mode shows a dashed, draggable crop box directly on the canvas with aspect presets — WYSIWYG instead of blind numbers.

9

Kept from v1

Per-image editing, upscale mode, do-not-enlarge guard, URL import, filename patterns, live size estimates, split compare, clipboard paste and the privacy pill — all carried over.

10

Features actually work

Adjust sliders and filters apply live to the preview, rotate/flip transforms the canvas, undo/redo works, the filmstrip reorders by drag, shortcuts (Ctrl+V, Del, [ ], C) function, URL import shows a real error state, and per-image overrides get a cyan dot when "apply to all" is off.

11

BG remover + more tools

Background remover with AI-style cutout preview, edge feather and backdrop swap (transparent / white / color / blurred). Text tool with draggable layers, Colors palette extracted per image (click to copy hex), plus straighten and vignette in Adjust.

12

v3 — design polish

Full SVG line-icon system replaces emoji, Inter typeface, calmer color tokens, tighter spacing rhythm, refined shadows, focus-visible rings, and smoother motion curves. Same features — new craft.
